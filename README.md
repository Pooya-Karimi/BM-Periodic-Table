🧪 Overview

BM Periodic Table is a desktop application developed by BloodMoon Studio to provide a clean, interactive, and accessible way to explore the chemical elements.

Instead of presenting the periodic table as a static chart, BM Periodic Table allows users to interact with individual elements and explore their information through a dedicated interface.

Select an element and discover its:

Basic Information
Physical Properties
Atomic Properties
Common Uses
History
Interesting Facts

The application is designed with simplicity in mind while keeping the experience visually clean and enjoyable.

✨ Features
🔬 Interactive Periodic Table

Every element is presented as an interactive button, allowing users to quickly select and explore it.

📋 Detailed Element Information

Each element provides organized information divided into dedicated sections for easier reading and navigation.

🎨 Category-Based Design

Elements are visually distinguished using category-specific colors, making it easier to recognize different groups at a glance.

📚 Educational Content

Explore more than just atomic numbers and symbols. Learn about element properties, applications, history, and interesting facts.

🖥️ Desktop Experience

Built as a native-feeling desktop application using Python and CustomTkinter.

⚡ Lightweight

The application is designed to remain simple, fast, and easy to use without unnecessary complexity.

📦 Requirements

Before running the application, make sure you have:

Python 3.x
CustomTkinter

Install the required dependency:

pip install customtkinter

🚀 Installation & Usage
1. Get the Project

Download the project from its official source.

2. Install Dependencies
pip install customtkinter

3. Verify the Project Files

The application expects the required resources to be available alongside the main program:

BM-Periodic-Table/
│
├── main.py
├── elements.json
├── icon.ico
└── README.md

4. Launch

Run:

python main.py


The BM Periodic Table window should open automatically.
